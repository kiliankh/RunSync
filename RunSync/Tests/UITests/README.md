# Tests d'interface

Répertoire réservé aux tests XCUITest : parcours d'onboarding, préparation de course,
écran live, résumé, réglages, accessibilité (VoiceOver, Dynamic Type, contraste, zones
tactiles ≥ 60 pt).

Ils seront écrits avec la cible de test d'interface lors de RS-032/RS-033, quand les écrans
auront leurs données réelles (capteurs et persistance) et que l'audit d'accessibilité
pourra s'appuyer sur des écrans stabilisés.
