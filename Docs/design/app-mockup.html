RunSync — maquette statique des écrans

Ceci n'est pas l'application. C'est un rendu HTML construit à partir du code SwiftUI réel (RunSync/Features/**) pour montrer la mise en page, les libellés et les états affichés. L'application iOS n'a pas pu être compilée ni lancée dans cet environnement (aucun macOS, aucun Xcode) : les couleurs, tailles de police SF et composants système (Dynamic Type, VoiceOver, boutons natifs) ne sont donc pas rendus à l'identique. Les chiffres affichés proviennent de la sortie réelle de swift run runsync-demo.
